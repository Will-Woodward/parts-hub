# PARTS HUB：深圳南山区登记、ICP备案与部署路线（2026-11）

## 1. 主体与住宅地址

拟采用大陆个体工商户、个人经营。申请前先向南山区对应街道政务服务中心/市场监管登记窗口核实：
- 住宅房屋编码是否可用于经营场所申报；
- 房屋用途、产权/租赁关系及房东授权材料要求；
- 是否需要物业/有利害关系业主同意或其他用途证明；
- 电子元器件批发/零售经营范围的可选规范表述。

深圳部分商事主体实行住所（经营场所）自主申报，但这不等于所有住宅均自动符合个体工商户登记条件。个体工商户登记管理规定要求经营场所合法使用证明；登记机关简化材料时仍会核验地址客观存在及申请人合法使用权。不得使用虚构地址或仅有虚拟空间的地址替代实体经营场所。

准备材料建议：经营者身份证、可用于申报的住宅房屋编码/地址信息、房产证或租赁合同及房东授权（按窗口要求）、联系方式、经营范围拟定稿。提交前以广东政务服务网及南山区登记窗口当期清单为准。

经营范围建议与实际交易匹配，向登记机关咨询规范项目，例如电子元器件批发、电子元器件零售、电子产品销售等；不要未经核实照抄，最终以系统可选目录和核准结果为准。

## 2. ICP备案

域名 `parts-hub.com` 应先完成注册商实名认证。主体取得营业执照后，使用个体工商户主体资料申请网站备案。若网站部署在中国内地服务器，需先经云厂商接入备案审核并取得备案号，再正式解析/开放大陆站点。香港服务器不走大陆ICP备案流程，但大陆访问速度、合规部署和支付机构审核需另行评估。

自营商品网上销售应依法办理市场主体登记并公示经营者主体信息。ICP备案与增值电信业务经营许可证不是同一概念；普通自营商城不应仅因收取商品货款就直接推断必然需要ICP经营许可证。若后续转为平台撮合、向第三方商家提供有偿信息/交易服务，应重新评估许可要求。

## 3. 推荐云部署

- 域名：`parts-hub.com`，注册人/实名认证主体与实际运营主体保持一致，避免先用他人身份注册。
- 云：腾讯云中国大陆地域（深圳/广州可选，按备案接入与业务延迟决定），轻量应用服务器或 CVM；正式环境建议独立数据库，不与应用共机。
- 应用：Next.js Node.js 服务，Nginx/Caddy 反向代理，HTTPS 证书自动续期。
- 数据：腾讯云 PostgreSQL（或同等级托管 PostgreSQL），启用自动备份、私网访问和最小权限账号。
- 图片：腾讯云 COS 私有写入、公开读/CDN 分发；后台上传采用短时签名 URL，限制文件类型和大小。
- 安全：安全组只开放 80/443/SSH（SSH 限制来源）；数据库不开放公网；密钥放服务器环境变量/密钥管理服务；定期备份和恢复演练。
- 环境：开发/预览先用本地或香港测试环境；取得营业执照、备案通过、支付商户审核后再切换正式大陆站。

## 4. 上线前的商业与合规项目

- 网站首页/经营页面显著公示营业执照主体信息、联系方式及备案号。
- 发布用户协议、隐私政策、退换货/售后规则、交付与运费规则。
- 寄售协议写明货权、销售授权、库存真实性、定价权限、结算周期、退货、质量责任和召回机制。
- 支付只接入官方微信支付/支付宝商户产品；先完成商户进件和产品审核，再接真实支付回调。不得仅凭代码里有支付按钮就开始收款。
- 商品信息须确认型号、品牌、数量、批次/Date Code、包装与真伪来源；避免把库存状态和可售库存混为一谈。
